## 🚚 NeuroFleetX — AI-Powered Urban Fleet & Traffic Intelligence

> **Enterprise-grade smart fleet management and urban mobility platform**

NeuroFleetX is a full-stack fleet intelligence platform designed to combine **real-time vehicle telemetry, intelligent route planning, load optimization, predictive maintenance, and role-based operational workflows** into a unified system.

### 🔥 Key Features

#### 🛡️ Security & RBAC

* Stateless JWT authentication
* Spring Security integration
* Secure login and registration
* Granular role-based permissions
* Protected frontend routes
* Four operational roles:

  * **Admin**
  * **Fleet Manager**
  * **Driver**
  * **Customer**

#### 🛰️ Real-Time Fleet Telemetry

* Live vehicle location monitoring
* GPS coordinate tracking
* Vehicle speed monitoring
* Fuel consumption tracking
* Engine health alerts
* Interactive Leaflet-based maps
* Demand heatmap visualization across Delhi NCR

#### ⚡ AI Route & Load Optimization

* Dynamic route planning
* Fastest route comparison
* Eco-friendly route selection
* Shortest route analysis
* Payload distribution
* Vehicle capacity management
* Axle overload prevention

#### 🔧 Predictive Maintenance

* Vehicle health monitoring
* Engine wear tracking
* Maintenance alerts
* Service scheduling
* Reduced unexpected vehicle downtime

#### 📊 Operational Dashboards

Role-specific dashboards for:

* Fleet administration
* Vehicle inventory
* Fleet monitoring
* Driver performance
* Customer bookings
* Revenue analytics
* Maintenance operations

#### 🎨 Advanced Frontend Experience

* Dark futuristic interface
* Glassmorphism UI
* 3D perspective animations
* Interactive vehicle visualizations
* Live telemetry simulator
* Dynamic safety alerts
* Real-time fuel and payload calculations
