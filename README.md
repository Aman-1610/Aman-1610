## 🚚 NeuroFleetX — AI-Powered Urban Fleet & Traffic Intelligence ⭐

An enterprise-grade smart fleet management and urban mobility platform built using **Spring Boot 3.2** and **React 19**. NeuroFleetX leverages AI-driven route optimization, predictive maintenance, real-time telemetry, and role-based dashboards to streamline fleet operations and improve transportation efficiency.

### ✨ Highlights

- 🔐 JWT Authentication with Spring Security
- 👥 Role-Based Access Control (Admin, Fleet Manager, Driver, Customer)
- 📍 Real-Time Vehicle Tracking using Leaflet Maps
- 🚛 AI-Based Route & Load Optimization
- 🔧 Predictive Vehicle Maintenance System
- 📊 Fleet Analytics & Performance Dashboard
- 🛰️ Live Telemetry Monitoring
- 🎨 Modern Glassmorphism UI with Interactive 3D Dashboard
- ☁️ Dockerized Deployment with Render & Netlify
- 🔄 RESTful APIs built using Spring Boot

### 🏗️ System Modules
